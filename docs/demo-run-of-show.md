# Two-minute stage plan

## Option A — animation and live narration

Play the 120-second deck and follow [the English talk track](demo-script.md). This is the reliable standalone version. It explains the concept, including an illustrated storyboard preview, without relying on the editor POC.

## Option B — slides plus the live editor

Use the level buttons and pause after each level. Rehearse the live editor before the event; its readiness and startup instructions are maintained in [the editor status note](video-gaming-agents-demo-status.md).

| Time | Surface | Presenter cue |
| --- | --- | --- |
| 00:00–00:12 | Level 1 — Press Start | "What if video editing felt like playing a game? Two agents, one adventure." |
| 00:12–00:25 | Level 2 — Footage Dungeon | "The story is hiding in our footage. Here, the surprise is an arcade inside an AI data center." |
| 00:25–00:45 | Level 3 — Context Agent | "See the scenes. Hear the words. Read the facts. Collect the clues into a searchable index." |
| 00:45–01:00 | Level 4 — Story Unlocked | "Add your context. Turn the clues into a hook and story beats. Save a Story cartridge." |
| 01:00–01:45 | Live editor POC | Select the AI data center cartridge, load it, request a short arcade cut, and play the result. Use the verified POC controls. |
| 01:45–02:00 | Level 8 — Quest Complete | "Context Agent: find the meaning. Video Agent: make the movie. Pick a cartridge. Press start." |

Have a rendered example ready before presenting. If a fresh render takes longer than the slot, show that prepared result and describe the current POC accurately. Do not promise a connected model backend while the planner is scripted.

## English live-demo prompt

> Make a 30-second short from this Story. Lead with the arcade surprise, keep the pacing tight, and add English captions.

Use the duration and aspect-ratio options actually supported by the ready POC. The architecture deck's chat is an illustration, so do the interactive portion in the editor.
