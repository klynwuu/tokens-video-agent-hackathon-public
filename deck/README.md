# Architecture deck source

Eight English levels, 120 seconds, built with the existing React/Remotion composition.

```sh
npm ci
npm run dev
```

The packaged interactive build is at `../public/deck/` and the existing rendered deck movie at `../public/videos/architecture-deck.mp4`. Rebuild the interactive deck with `npm run build -- --base=./` and copy `dist/` into `../public/deck/`.

This deck explains the conceptual Context Agent → Story cartridge → Video Agent handoff. Its storyboard preview illustrates the design. The public portal separately plays the completed original-footage exports and the actual recorded prototype demonstration.
